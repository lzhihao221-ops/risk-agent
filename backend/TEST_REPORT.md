## 技术栈
- OCR引擎: Tesseract 5.5.2 + Python pytesseract
- 地图: Leaflet + OpenStreetMap（免费开源）
- AI模型: Ollama + gemma3:12b（本地部署）
- 后端: Spring Boot + MyBatis
- 前端: Vue 3 + Element Plus

## 注意事项
1. AI响应需要10-30秒（本地模型加载中）
2. OCR识别需要几秒钟处理时间
3. GIS地图首次加载需要下载地图瓦片
4. 中文识别需要图片中有清晰的中文字符
