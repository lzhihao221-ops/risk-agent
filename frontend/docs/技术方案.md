## 二、数据库设计

### 2.1 企业基本信息表（risk_company）

```sql
CREATE TABLE risk_company (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '企业ID',
    company_name    VARCHAR(200) NOT NULL COMMENT '企业名称',
    credit_code     VARCHAR(50) COMMENT '统一社会信用代码',
    legal_person    VARCHAR(50) COMMENT '法定代表人',
    reg_capital     DECIMAL(15,2) COMMENT '注册资本（万元）',
    establish_date  DATE COMMENT '成立日期',
    industry        VARCHAR(100) COMMENT '所属行业',
    province        VARCHAR(50) COMMENT '省份',
    city            VARCHAR(50) COMMENT '城市',
    district        VARCHAR(50) COMMENT '区县',
    address         VARCHAR(500) COMMENT '注册地址',
    business_scope  TEXT COMMENT '经营范围',
    status          TINYINT DEFAULT 1 COMMENT '状态：1正常 2注销 3吊销',
    risk_level      TINYINT DEFAULT 0 COMMENT '风险等级：0未评估 1低 2中 3高 4极高',
    last_scan_time  DATETIME COMMENT '最近扫描时间',
    create_time     DATETIME DEFAULT CURRENT_TIMESTAMP,
    update_time     DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_credit_code (credit_code),
    INDEX idx_company_name (company_name),
    INDEX idx_risk_level (risk_level)
) COMMENT '企业基本信息表';
```

### 2.2 企业关联方表（risk_company_relation）

```sql
CREATE TABLE risk_company_relation (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    company_id      BIGINT NOT NULL COMMENT '主体企业ID',
    related_company VARCHAR(200) COMMENT '关联企业名称',
    related_person  VARCHAR(50) COMMENT '关联自然人',
    relation_type   VARCHAR(50) COMMENT '关联类型：股权/担保/实控人/高管/亲属',
    relation_detail VARCHAR(500) COMMENT '关联详情（如持股比例、担保金额）',
    data_source     VARCHAR(50) COMMENT '数据来源：工商/司法/手动',
    create_time     DATETIME DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_company_id (company_id),
    INDEX idx_relation_type (relation_type)
) COMMENT '企业关联方表';
```

### 2.3 风险事件表（risk_event）

```sql
CREATE TABLE risk_event (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    company_id      BIGINT NOT NULL COMMENT '企业ID',
    event_type      VARCHAR(50) NOT NULL COMMENT '事件类型',
    -- 事件类型枚举：
    -- LAWSUIT: 涉诉
    -- EXECUTION: 被执行
    -- ABNORMAL: 经营异常
    -- PENALTY: 行政处罚
    -- CHANGE_LEGAL: 法人变更
    -- CHANGE_CAPITAL: 注册资本变更
    -- TAX: 税务异常
    -- NEGATIVE: 负面舆情
    event_title     VARCHAR(500) COMMENT '事件标题',
    event_content   TEXT COMMENT '事件内容',
    event_date      DATE COMMENT '事件日期',
    severity        TINYINT DEFAULT 2 COMMENT '严重程度：1低 2中 3高',
    is_read         TINYINT DEFAULT 0 COMMENT '是否已读：0未读 1已读',
    is_handled      TINYINT DEFAULT 0 COMMENT '是否已处理：0未处理 1已处理',
    data_source     VARCHAR(50) COMMENT '数据来源',
    create_time     DATETIME DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_company_id (company_id),
    INDEX idx_event_type (event_type),
    INDEX idx_severity (severity),
    INDEX idx_is_read (is_read),
    INDEX idx_event_date (event_date)
) COMMENT '风险事件表';
```

### 2.4 贷后检查任务表（risk_check_task）


### 2.5 预警规则表（risk_alert_rule）

```sql
CREATE TABLE risk_alert_rule (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    rule_name       VARCHAR(200) NOT NULL COMMENT '规则名称',
    rule_type       VARCHAR(50) COMMENT '规则类型：事件触发/指标触发/组合触发',
    event_type      VARCHAR(50) COMMENT '触发事件类型（事件触发时有效）',
    indicator_code  VARCHAR(50) COMMENT '指标编码（指标触发时有效）',
    operator        VARCHAR(20) COMMENT '比较运算符：gt/gte/lt/lte/eq/neq',
    threshold_value VARCHAR(100) COMMENT '阈值',

    create_time     DATETIME DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_rule_type (rule_type)
) COMMENT '预警规则表';
```

## 三、模块设计

### 3.1 企业风险画像模块

**功能：**
- 企业基本信息展示（工商信息）
- 风险评分卡（综合评分 = 司法风险×30% + 经营风险×25% + 关联风险×25% + 舆情风险×20%）
- 风险事件时间线
- 关联图谱可视化（ECharts graph）

**核心接口：**
```
GET  /api/risk/company/{id}              # 企业详情
GET  /api/risk/company/{id}/score        # 风险评分
GET  /api/risk/company/{id}/events       # 风险事件列表
GET  /api/risk/company/{id}/relations    # 关联图谱数据
POST /api/risk/company/scan              # 触发企业风险扫描
```

### 3.2 预警推送模块

**功能：**
- 实时预警列表（未处理/按严重程度排序）
- 预警规则配置（可视化配置界面）
- 推送渠道（站内消息 + 短信 + 企业微信/钉钉）
- 预警统计看板

**核心接口：**
```
GET  /api/risk/alert/list                # 预警列表
POST /api/risk/alert/handle/{id}         # 处理预警
GET  /api/risk/alert/statistics          # 预警统计
POST /api/risk/alert-rule                # 创建规则
PUT  /api/risk/alert-rule/{id}           # 修改规则
```

### 3.3 任务管理模块

**功能：**
- 贷后检查任务分配
- 检查模板管理（常规检查模板、专项检查模板）
- 任务到期提醒
- 检查报告归档
- 任务统计看板

**核心接口：**
```
GET  /api/risk/task/list                 # 任务列表
POST /api/risk/task                      # 创建任务
PUT  /api/risk/task/{id}                 # 更新任务
POST /api/risk/task/{id}/complete        # 完成任务
GET  /api/risk/task/statistics           # 任务统计
```

## 四、数据源对接

### 4.1 第一期（MVP）数据源

| 数据源 | 提供方 | API | 费用 | 用途 |
|--------|--------|-----|------|------|
| 工商信息 | 天眼查/企查查 | 企业工商查询 | ~0.5元/次 | 企业基本信息、股权结构 |
| 司法数据 | 中国裁判文书网/聚法 | 案件查询 | ~1元/次 | 涉诉、被执行信息 |
| 经营异常 | 国家企业信用公示 | 公示信息查询 | 免费/低成本 | 经营异常、行政处罚 |
| 舆情数据 | 新浪舆情/清博 | 舆情监测 | 按年付费 | 负面舆情预警 |

### 4.2 数据采集适配器设计

采用**适配器模式**，每个数据源一个适配器，方便替换和扩展：

```java
public interface DataProviderAdapter {
    /** 数据源标识 */
    String getProviderName();
    /** 查询企业工商信息 */
    CompanyInfo queryCompanyInfo(String creditCode);
    /** 查询企业风险事件 */
    List<RiskEvent> queryRiskEvents(String creditCode);
    /** 查询企业关联方 */
    List<CompanyRelation> queryRelations(String creditCode);
}
```

## 七、技术选型说明

| 技术 | 选择 | 理由 |
|------|------|------|
| 后端框架 | Spring Boot 3.x + MyBatis | 稳定可靠，模块化设计，易于扩展 |
| 前端框架 | Vue 3 + Element Plus + Vite | 组件丰富，开发效率高 |
| 图谱可视化 | ECharts Graph | 开源免费，支持力导向图 |
| 任务调度 | XXL-JOB | 定时扫描、批量处理 |
| 缓存 | Redis | 数据源结果缓存，降低API调用成本 |
| 部署 | Docker + 私有化部署 | 满足银行数据不出域要求 |
